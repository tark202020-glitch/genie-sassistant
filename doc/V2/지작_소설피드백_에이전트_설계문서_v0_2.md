# 지작(JIZAK) 소설 피드백 에이전트 — 설계 문서 v0.2

*작성: 2026.9.30 / 근거: 초고 수정 프로토콜 v0.2, 『요리는 잘 하는 사람』 1·2부 편집 실측*
*v0.1 → v0.2 변경: 실행 시점의 사용자는 작가 한 사람이며 입력은 초고뿐이라는 전제로 전면 개정. 편집자 관련 요소는 모두 학습·평가 경로로 이동.*
*대상 독자: 에이전트 개발자 / 상태: 실 서비스 전 지속 갱신 / 다이어그램: 별도 PNG 6종*

---

## 1. 목적과 전제

**목적.** 작가가 초고를 올리면, 편집자가 하던 피드백을 에이전트가 만들어 작가에게 직접 준다. 지작 프로그램의 핵심 엔진.

**실행 시점 전제**
- 사용자는 작가 한 사람. 입력은 초고(부·장·전체). 선택 입력: 시놉시스·설정 메모·인물표.
- 편집자 메모, 형광 마크, 바이블, 설정집, 이전 총정리는 **없다.** 에이전트가 원고에서 스스로 만든다.
- 사람이 개입하는 지점은 작가의 '확인 질문 답변'뿐이다. 답하지 않아도 피드백은 나온다.
- 출력은 작가에게 직접 가는 문서다. 편집자용 내부 프레임은 출력에 포함하지 않는다.

**학습·평가 시점 전제**
- 편집자(대표)의 메모·판단·설정 확정 대화는 골드 데이터다. 에이전트는 이 판단을 재현하도록 조정된다.
- 편집자 인터페이스는 실행 경로가 아니라 **골드 데이터 생산·평가 도구**다.

**하지 않는 것**
- 대체 문장·대체 장면을 쓰지 않는다(교정 층위 제외).
- 에세이·시나리오는 형제 에이전트가 담당한다.

## 2. 두 개의 경로

```
[실행 경로]  작가 → 초고 → 에이전트 → 피드백 문서 → 작가 (확인 질문 답변 → 갱신)
[학습 경로]  편집자 실측(메모·총정리·설정 대화·정정) → 골드 데이터 → 규칙·프롬프트 조정 → 회귀 테스트 → 릴리즈
```

두 경로는 코드가 다르다. 실행 경로에는 편집자 개념이 없다. 학습 경로의 산출물(규칙 가중치·프롬프트·도메인 사전·판정 예시)만 실행 경로로 들어간다.

## 4. 분석 프로세스

### 4-1. 전체 흐름 (다이어그램 04-1)
![[04-1_전체흐름.png]]

```
원고 입력 → 단계 판별 → 모드 I / D / R / F
모드 D·R → 0.5 시놉시스 대조(시놉시스가 있을 때만)
→ 1 구조화(+설정 추출 +지식 상태표) → 2 문체 → 3 장점 → 4 결함 → 5 물음표 → 6 방향
→ 피드백 문서 생성 → 작가
작가 답변(있으면) → 7 설정 반영 → 문서 갱신
```

v0.1과의 차이: 편집자 판단 지점이 모두 사라졌다. 0.5는 편집자 대신 "작가가 준 시놉시스"와 대조하고, 시놉시스가 없으면 건너뛴다. 7은 편집자와의 확정 대화가 아니라 작가 답변의 반영이다.

### 4-2. 초고 모드 상세 (다이어그램 04-2)
![[04-2_초고모드_상세.png]]
| 단계 | 하는 일 | 편집자 없이 어떻게 하는가 |
|---|---|---|
| 1 구조화 | 장면 분할 → 인물·타임라인 → 반복 장치 → **설정 추출** → 지식 상태표 | 설정 추출: 원고에서 숫자·규칙·물건·직업 서술을 모아 설정집 초안을 만든다. 원고가 같은 항목을 다르게 말하면(복용 주기 세 가지) 충돌로 기록 |
| 2 문체 | 시점·시제·장면/요약 비율·서술자 문장 샘플·초점 인물·장르 신호 | 원고 자체가 기준. "이 원고는 현재형이고 서술자가 세계를 비꼰다"가 이후 판정의 전제 |
| 3 장점 | 후보 수집 → 삭제 테스트 → 약속 이행 테스트 → 개성 테스트 → 유형화 → planted/fired | §5 |
| 4 결함 | R26(시놉시스 대조) → R25 → R17·R18 → R8 → R30 → 나머지 | 규칙은 학습 경로에서 조정된 것 |
| 5 물음표 | 원고 내 해결 검사 → 5분류 | '바이블' 분류는 '설계'로 이름 변경: 부 단위 수정이 아니라 작품 설계 질문 |
| 6 방향 | A급 1~3 → 후보안 → 설정집 초안 diff → 앞부분 갱신 → 작가 질문 목록 | 대사 교체표는 없다(편집자 line 마크가 없으므로) |

### 4-3. 학습 데이터 파이프라인 (다이어그램 04-3, 실행 경로 아님)
![[04-3_학습데이터_파이프라인.png]]
```
편집자 손글씨 메모 PDF → OCR·위치 매핑 → 판독 신뢰도 → 종류 분류(fix/line/question/design/correction)
→ 골드 데이터(장점 정답·결함 정답·물음표 정답·대사 교체 정답·설정 확정치·이견)
→ 규칙별 채택률 · 프롬프트 예시 · 도메인 사전
→ 회귀 테스트 → 릴리즈
```

편집자의 `line` 마크(대체 대사)는 실행 시 출력되지 않는다. 학습 경로에서 "어떤 문장이 왜 더 나은가"의 기제 사전(무지 유지·구체화·화법 전환·단어 회피 등)을 만드는 데 쓰이고, 그 기제는 실행 시 결함의 `direction`(방향 설명)에 반영된다.

## 5. 장점 추출 로직

편집자 형광 마크 없이 원고 자기 기준으로 돌아간다.

**5-1. 약속 읽기(단계 2의 산출물).** 시점·시제, 서술자가 인물을 논평하는가 세계를 논평하는가, 장르 신호(웃음의 기제, 긴장의 기제), 반복 장치 목록. 이것이 '이 원고가 잘한 것'을 판정하는 유일한 기준이다.

**5-2. 후보 수집(원고 신호).**
- 장면을 닫는 마지막 대사·행동
- 시간 표시가 붙은 공정 서술(현재형 원고에서 카운트다운이 되는 곳)
- 서술자가 인물이 아니라 세계를 향해 말하는 문장
- 반복 장치의 첫 등장과 재등장
- 이전 부에 `planted`로 기록된 항목의 재등장

**5-3. 세 테스트.**
![[05-3_수정고모드_절차.png]]
| 테스트 | 질문 | 구현 |
|---|---|---|
| 삭제 | 그 문장 뒤의 해설·감정 서술을 지워도 장면이 서는가 | 후속 문장을 제거한 버전과 비교 판정. 서면 문장은 장점, 지운 부분은 R3·R17 후보 |
| 약속 이행 | 5-1의 약속을 이행하는가. 장르 기제가 설명되는가 | 기제를 한 문장으로 쓰지 못하면 탈락 |
| 개성 | 이 작가만 쓰는 문장인가 | 두 근사: ①같은 문맥에서 모델의 예측 불가능성이 높은가 ②원고 안의 다른 후보와 같은 기제를 반복하는가(반복되는 습관 = 개성, 한 번뿐인 튀는 문장 = 우연) |

**5-4. 유형화.** 통과한 후보를 기제가 같은 것끼리 묶고 이름을 붙인다(한 줄 대사 / 실시간 공정 / 서술자 위트 / 극단=성격 …). 유형마다 인용 2~4개와 보호 지시("손대지 않는다 / 뒤의 해설만 지운다 / 이 톤을 다른 장면에도")를 붙인다. 유형의 부정형이 결함 규칙과 연결된다(한 줄 대사 ↔ R3, 서술자 위트 ↔ R17).

**5-5. planted / fired.** 부 사이의 구조 장점. 앞부분 분석 결과에 `planted`로 저장된 항목이 이번 부에서 격발되면 `fired`. 격발되지 않은 것은 복선표에 남는다.

**5-6. 학습 경로의 역할.** 편집자 형광 마크는 5-3 개성 테스트의 정답지다. 지표 '장점 재현율'은 이 정답지 대비 재현율이다. 실행 시에는 쓰이지 않는다.

## 6. 원고 단계와 모드

### 6-1. 판별
| 단계 | 신호 | 작가 확인 |
|---|---|---|
| 아이디어 | 시놉시스·설정 메모·인물표. 장면 서술 < 20% | 필요 시 질문 |
| 초고 | 장면 서술 존재, 이전 버전 없음 | 기본값 |
| 수정고 | 이전 버전 + 이전 피드백 존재 | 작가가 '수정고'로 올림 |
| 완고 | A급 0건, 설정 충돌 0건 | 작가 지정 |

자동 판별은 추정이고, 작가가 업로드 시 단계를 고르면 그것을 따른다.

### 6-2. 모드별 작동
| 항목 | 모드 I 아이디어 | 모드 D 초고 | 모드 R 수정고 | 모드 F 완고 |
|---|---|---|---|---|
| 실행 단계 | 1(설정·인물·타임라인만)·5·6 | 0.5·1~6, 7(답변 시) | 0.5·R-diff·1·4(증분)·5·6 | 1·4(F 집합)·6(교정표) |
| 활성 규칙 | 설정·타임라인·역할 축·시놉시스 대조 | R1~R34 | 이전 피드백 반영 검증 + 신규 + 회귀 | 일관성·복선 회수·고유명사·실명 리스크·교정 |
| 출력 | 질문 목록 + 설정집 초안 | 피드백 문서(장점→A급→설정→확인 질문) | 반영표 + 증분 피드백 | 교정표 + 리스크 + 회수표 |
| 작가 질문 | 주 출력 | 확인 n + 고를 것 n + 참고 n | 변형된 항목의 의도 확인 | 최소 |
| 톤 | 질문. 단정 없음 | 장점 먼저, 크게 하나 | 반영된 것을 먼저 인정 | 고칠 것만 |

### 6-3. 수정고 모드 (다이어그램 05-3)
![[06-3_규칙_생애주기.png]]
이전 버전과 장면 단위 diff → 이전 피드백 항목을 변경 장면에 매핑 → 반영/미반영/변형 판정 → 변경 장면의 지식 상태·설정 일관성 재계산(회귀) → 증분 결함 탐지 → 반영표 + 증분 피드백. '이전 피드백'은 에이전트가 자체 저장한 것이다.

## 7. 규칙 엔진 (다이어그램 06-3)

규칙 스키마·카테고리·생애주기는 v0.1 §6과 같다. 바뀐 점:
- R26 '바이블 대조'는 '시놉시스 대조'로. 작가가 시놉시스를 주지 않으면 비활성.
- R29 '대사 교체 근거화'는 실행 경로에서 제외. 학습 경로에서 기제 사전 구축용.
- 규칙 생애주기의 '채택률'은 두 출처를 가진다: 학습 경로의 편집자 채택률, 실행 경로의 작가 반응(수정고에서 반영됐는가).

## 8. 설정집 자동 생성과 작가 질문

편집자와의 설정 확정 대화(2부 실측: 가격→복용량→통→반입→온도)를 작가 대상으로 바꾼 것.

1. 단계 1이 원고에서 설정 항목을 추출한다. 항목마다 원고가 말한 값과 위치를 모은다.
2. 같은 항목에 값이 둘 이상이면 '충돌', 값이 없는데 플롯이 의존하면 '공백'.
3. 충돌·공백을 작가 질문으로 바꾼다. 형식: "복용 주기가 원고에 세 가지로 나옵니다(101·104·123쪽). 정해져 있습니까?" 편집자처럼 값을 정해주지 않는다. 후보 수치는 현실 근거(웹 검색·도메인 사전)와 함께 참고로만 붙인다.
4. 작가가 답하면 설정집에 반영하고, 파생 문장 목록(그 값으로 바뀌어야 할 원고 위치)을 문서에 추가한다.
5. 답하지 않으면 충돌·공백 상태로 남기고 다음 부에서 다시 묻지 않는다(반복 질문 금지).

## 9. 출력 문서 형식 (작가에게 직접)

1. 장점 — 유형별, 인용, 보호 지시
2. 가장 큰 것 하나~셋(A급) — 문제, 근거, 방향, (있으면) 후보안
3. 인물·서술 — 작가 대입 목록, 변명 서술, 일관성
4. 설정집 초안 — 원고에서 뽑은 값, 충돌, 공백
5. 확인 질문 — 확인 n / 고를 것 n / 참고 n
6. 교정
7. (앞부분이 있으면) 앞부분 피드백 갱신 항목

넣지 않는 것: 편집 프레임(작품 해석·이론 참조), 기각된 후보안, 대체 문장.

## 10. 컨텍스트와 저장

- 부 단위 세션. 부가 끝나면 피드백 문서·설정집·planted 목록·지식 상태표를 자체 저장소에 저장. 다음 부는 그것을 로드한다.
- 장면 단위 청킹, 쪽 번호는 작가 원고 기준 유지.
- 웹 검색은 설정 질문의 참고 수치에만. 원고 문장을 질의에 넣지 않는다.

## 11. 학습·평가 운영

### 11-1. 골드 데이터(편집자 실측에서)
메모 전사 / 부 총정리 / 대사 교체표(기제 사전용) / 지식 상태 골드 / 설정 확정치 / 정정 로그·이견 / 설계 큐. 3·4부 완료 시 한 작품 전체. 두 번째 작품에서 과적합 검증.

### 11-2. 지표
| 지표 | 정의 | 목표 |
|---|---|---|
| A급 일치 | 에이전트 A급 ∩ 편집자 A급 / 편집자 A급 | ≥ 0.8 |
| 장점 재현 | 편집자 장점 유형 재현율 | ≥ 0.8 |
| 작가 대입 정밀도 | R17·R18 탐지 중 편집자 채택 | ≥ 0.75 |
| 지식 상태 탐지 | 정보 설계 A급을 A급으로 | 일치 |
| 설정 충돌 재현 | 편집자가 연 설정 항목을 에이전트가 충돌·공백으로 냈는가 | ≥ 0.8 |
| 근거 유효율 | 생성 인용 0건 | 1.0 |
| 작가 반응(실행 경로) | 수정고에서 A급이 반영된 비율 / 질문 응답률 | 추적 |

### 11-3. 회귀·버전
1·2부 원고를 초고만으로 입력해 골드와 비교. 편집자 메모 없이 편의점 장면을 A급으로 내지 못하면 릴리즈하지 않는다. 버전 4종(프로토콜·규칙·프롬프트·골드) 관리.

## 12. 제약
대체 문장 금지 / 근거 없는 출력 금지 / 실명 리스크 최우선 보고 / 원고 외부 유출 금지 / 반복 질문 금지 / 작가가 답하지 않아도 피드백은 완결되어야 함.

## 14. 미결
- 개성 테스트의 두 근사가 편집자 형광과 얼마나 일치하는지 — 첫 회귀에서 측정
- 설정 추출의 재현율 — 원고가 암시만 하는 설정(직업 관행)을 얼마나 잡는가
- 작가 질문의 적정 개수 — 2부 실측은 편집자 기준 15건. 작가에게는 더 적어야 할 수 있음
- 시놉시스 형식 — 작가가 무엇을 어떤 형식으로 주면 0.5가 작동하는가

# 린다포인트 — 『시나리오 거듭나기』(린다 시거)의 소설 적용 원칙

*2026-10-09 제정. 원전: `doc/V2/시나리오거듭나기_요약.txt` (23쪽 요약본)*
*"린다포인트" = 린다 시거의 리라이팅 체크 체계를 소설용으로 번역해 피드백 에이전트에 이식한 점검 축. 피드백 화면에서 린다포인트 유래 지적은 「린다」 표식 + 점선 밑줄로 구분 표시한다.*

## 0. 전제 — 철학의 일치

시거의 서문: "리라이팅은 극본 속에서 그 기능을 발휘하지 못하는 부분만을 고쳐 쓰고 나머지는 그대로 남기는 것." 이는 에이전트의 제1원칙(장점 보호, 살릴 것을 먼저)과 동일하다. 따라서 린다포인트는 새 철학이 아니라 **구조 진단 축의 보강**이다.

**우선순위 원칙**: 린다포인트는 외부 이론이다. 우리 편집자 골드(실제 편집 행동)와 충돌하면 **편집자 골드가 우선**한다. 충돌 사례는 이 문서에 기록한다.

## 1. 전환표 — 시나리오 → 소설

### A. 그대로 (매체 무관)
| 시거 원칙 | 에이전트 대응 |
|---|---|
| 중심 질문: 설정에서 던지고, 전환점마다 다시 던지고, 클라이맥스에서 답한다 | 단계 6 구조 검사 ③ 정밀화 |
| 암시-페이오프: 결말이 필요로 하는 것은 모두 시작 어딘가에 설정 | planted/fired 추적 (기존) |
| 모티브 3회 반복, 반복과 대비 | devices (기존) |
| 동기-행동-목표 캐릭터 골격, 위험요소(잃을 것) | **R49 신설** |
| 갈등 5타입, 메인 갈등 단일 초점 | R49 action에 포함 |
| 인물 기능론: 기능 없는 인물 삭제, 동일 역할 병합, 주요 인물 3~4명 | **R48 신설** |
| 수동적 주인공 금지 (중반 이후 능동 전환) | R48 detect에 포함 |
| 서브플롯도 3막 구성, 메인과 교차, 3~4개 상한, 첫 부분 배치 금지 | **R47 신설** |
| 액션포인트 5종(전환점·미드포인트·장벽·복잡화·반전), 장벽 과다=반복, 반전 2개면 충분, "액션 추가는 박진감을 해결하지 않는다" | **R46 신설** |
| 3막 골격: 카타리스트→제1전환점→미드포인트→로우포인트(+새 정보)→클라이맥스 | **단계 1 story_spine 신설** |

### B. 단위 번역
| 시나리오 | 소설 |
|---|---|
| 씬 | 장면(소설) / 꼭지(에세이) |
| 분·페이지 (30분=1전환점) | **분량 비율** (약 25% 지점 / 2전환점 약 75~80% / 설정 15% 이내) |
| 몽타주 | 요약 서술 — "정보 전달만 하고 갈등을 진전시키지 않는 구간" |
| "대사가 아니라 시각적으로" | "서술자의 설명이 아니라 장면으로" (R3·R37과 공명) |
| 75~100씬 | 장면 수는 유동 — 비율·기능만 검사 |

### C. 뒤집기 — 소설에서는 반대
| 시나리오 원칙 | 소설 번역 | 근거 |
|---|---|---|
| 내적 갈등은 문제의 원인 — 밖으로 드러내라 | 내면 서술은 **자산**. 단 내적 갈등이 행동·관계에 영향을 미치는지 검사 (고여만 있으면 지적) | 시거 본인: "내적 갈등은 소설에서 제대로 기능을 발휘한다" |
| 회상 금지 | 회상 **절제** — 합법적 기법이되, 동기가 회상·설명에만 의존하면 지적 ("진정한 동기는 현재의 행동에") | 소설의 시간 자유 |
| 시각 전달 강제 | 장면화 **권장** — 서술자는 말할 권리가 있음. 경계선은 R17(작가 대입): 인물의 내면은 OK, 작가의 침입은 NO | 매체 차이 |

### D. 버리기
프리크레딧, 인터컷, 캐스팅·배우, 마케팅 통계, 상영 시간 공식 등 영화 제작 실무.

## 2. 이식 목록 (FA-0.17)

- **단계 1 — story_spine(스토리 골격 매핑)**: 카타리스트 / 중심 질문 / 제1전환점 / 미드포인트 / 로우포인트(+새 정보) / 클라이맥스의 위치를 쪽과 **분량 비율(%)**로 매핑. 없으면 "부재", 비율이 크게 어긋나면 그 사실 기록. 완성본에만 확정 판정(미완성은 잠정).
- **R45 스토리 골격 정합성**: 골격 요소의 부재·위치 이탈을 결함으로 (예: 설정이 40%까지 — "설정이 길수록 구성이 무너진다").
- **R46 박진감 진단**: 처지는 중반을 액션포인트로 분해 — 장벽 과다(단순 반복), 복잡화 부재(기대감 없음), 반전 과다(2개면 충분)·부재. "액션 추가는 박진감을 해결하지 않는다".
- **R47 서브플롯 구조**: 서브플롯의 3막 구성 유무, 메인플롯과의 교차, 개수(3~4 상한), 첫 부분 배치로 메인 오인 위험.
- **R48 인물 기능·경제**: 기능 없는 인물 열거, 동일 역할 병합 제안, 주요 인물 수, 수동적 주인공(중반 이후) 검사.
- **R49 동기-행동-목표 골격**: 주인공별 골격 한 줄 요약 가능성, 동기의 현재성(회상·설명 의존 지적), 위험요소(잃을 것) 명확성, 메인 갈등 단일 초점(갈등 5타입 분류).
- **단계 6 구조 검사 ③ 정밀화**: "추진 질문이 결말에서 답해지는가" → "+ 전환점마다 다시 던져지는가".

적용 범위: R45~R49는 **소설 전용**(에세이는 독자축 구조라 건너뜀 — E6·신호⑩이 대응). 에세이 저자 에피소드 꼭지에는 R49(동기 골격)만 참고 적용.

## 3. 화면 표시 규약

린다포인트 유래 산출물은 피드백 화면에서 구분 표시한다:
- 판정 카드: 제목에 **점선 밑줄** + 「린다」 미니 표식 (호버 시 "린다포인트 — 시나리오 거듭나기 원칙" 툴팁)
- 단계 1의 스토리 골격 섹션: 섹션 제목에 「린다」 표식
- 식별 기준: rule_id ∈ {R45,R46,R47,R48,R49} 또는 story_spine 필드

## 4. 골드 충돌 기록 (지속 갱신)

- (아직 없음) — 회귀 실행에서 편집자 골드와 어긋나는 린다포인트 판정이 나오면 여기 기록하고 규칙을 조정한다.

## 1. 진단 — v0.2 에이전트와 이상적 피드백의 구조 차이

사용자 지적 2건(총평 부족, 감정 흐름 누락)을 골드 문서로 확인한 결과, 근본 원인은 **구성 단위의 차이**다.

| 축 | 이상적 피드백 (고래방 전체 피드백 실측) | v0.2 에이전트 |
|---|---|---|
| 구성 단위 | **인물 중심** — ▮살리고 싶은 것이 [이정은]·[진영준]·[윤현채] 인물 섹션으로 구성. 인물마다 "한 줄 정의 → 핵심 기제 → 빛나는 순간 → 일관성이 흔들리는 지점(번호) → 재설계 방향" | 규칙(R)·단계 중심. 인물은 구조화의 부속 정보 |
| 감정 | 감정 전환이 장점·방향의 핵심 기준 — "도시락을 먹고 냉소→호감 반전", "세 번의 식사 장면에서 현채의 생각·감정이 더 묘사되었으면" | 감정 축 부재 (지식 상태표만 있음) |
| 총평 | 작품 단위 — 주인공의 궤적(추락→재기→승부수), 풍자의 **구조** 평가, "3부 서재 장면부터 방향이 흔들린다"는 전환점 지목, "잘 읽히는 장면의 공통점"(디테일 확보) 메타 분석 | 부 단위 A급 1~3건 + 2~3문장 요약 |
| 설정 공백 | 후보 수치를 현실 근거로 **계산해서** 제안 (빚 8.7억·월 상환 1974만, 포르티시모 250mg·2주 380만·금의 5.6배) | 질문 변환까지는 동일, 수치 계산 제안은 약함 |
| 표현 | 시제 전략(공정 장면=현재형, 나머지=과거형, 전환 규칙 필요), 정보 없는 지시문 최소화 | 문체 프로파일이 관찰만 하고 전략 제안 없음 |

## 2. 적용된 변경 (2026-10-04, 코드 반영 완료)

1. **단계 1 구조화 + `emotion_arcs`** — 주요 인물별 장면 순서 감정 추적. 전환점(is_turning_point)에는 전환을 일으킨 **계기(trigger — 음식·행동·대사 같은 구체물)**를 원문 근거와 함께 기록. 계기가 원문에 없으면 "계기 미서술"로 표시.
2. **단계 3 장점 — 감정 축 추가** — 후보 신호에 "감정·태도 전환 장면"과 "관계가 밀착되는 순간" 추가. 약속 이행 테스트에 "전환의 계기가 구체물로 제시되어야 통과". 유형에 "감정 전환의 구체물".
3. **단계 4 — R35 신설** ("감정 전환의 묘사 공백"): 전환점인데 인물의 생각·감정 묘사가 없거나 계기가 구체물로 제시되지 않으면 결함. 실행 순서 R26 → R25 → **R35** → R17·R18 → …
4. **단계 6 — 작품 단위 총평 재구성** — 출력에 `overall`(logline / 주인공의 궤적 / 구조·주제 평가와 방향이 흔들리는 지점 / 잘 읽히는 장면의 공통점)과 `character_reviews`(인물별: 한 줄 정의·핵심 기제·빛나는 순간·흔들리는 지점·감정 노트) 추가. 구성 순서를 이상적 피드백과 동일하게 "살리고 싶은 것(인물) → 비어있는 설정 → 풀리지 않는 전체 질문".
5. **읽기 뷰** — 감정 흐름 타임라인(전환점 강조), 작품 단위 평가 표, 인물별 리뷰 카드.

## 7. 두 번째 작품 골드 — 『월천거사 용시비결』 (2026-10-09)

**입수 자료**: 2초고 원고(80쪽, 6.2만 자) + 2초고 피드백(67쪽) + 3수정고 원고(61쪽). ※ "3수정고_피드백"은 잘못 첨부된 파일(타 도서)이었고, 실제 수정고 피드백은 **아직 작성 전** (사용자 확인 2026-10-09). 입수되면 수정고(R) 모드의 반영 판정 골드로 추가한다. 2초고 피드백의 장별 부분(9쪽~)은 원고 재수록본(인라인 수정 없음)으로 판정, 골드는 서두의 수정 피드백(1~8쪽).

**이 골드가 가르친 새 원칙 — "재설계형" 개입** (요리 1고 피드백=비평형과 대비):
구조가 아직 서지 않은 원고에는 편집자가 설계 수준의 수정안을 직접 쓴다 —
1. 테마 한 줄 재정의 ("최대 반전은 미래의 내가 아니라 아내가 쌓아온 20년")
2. 개정 시놉시스 전문 + 괄호 증폭 지시("(훨씬 극적으로)", "(죄책감 강조)")
3. 목차 비교표 (기존 차례 ↔ 수정 차례, 장별 한 줄 메시지)
4. 용어·은유 통일표 (무공=업무 능력, 주화입마=공황장애, 천시문→AI+위기서고 재정의)
5. 수치 처방 + 현실 검증 (분량 4~5쪽, 각주 쪽당 1개 이하, 타임라인 10년 단위 재설계, **복리 실수익률 계산으로 1억 5천→1억 3,700만 정정**)
6. 장르 기제 처방 (무협 활극 추가, 웃픈 톤, 언어유희 각주 — 실화 검색어까지)

**적용(코드)**: prompts v.9 — 단계 6에 intervention 판정(critique/redesign, 재설계 조건 4종 중 2+) + redesign 블록(theme·toc_proposal·term_table·prescriptions·synopsis_sketch). COMMON의 대체 금지 원칙을 "장면·문장 단위"로 한정(설계 수준 제안 허용). R39 '용어·은유 체계 통일' 신설. 읽기 뷰에 재설계 제안 섹션.

**추가 확보된 것**: 2초고 피드백 + 3수정고 원고 쌍 = **수정고(R) 모드의 반영 판정 골드** (피드백 항목이 수정고에 어떻게 반영됐는지 실측 가능 — 예: 목차가 피드백의 수정 차례대로 바뀜). R모드 구현 시 1차 검증 자료로 사용.
**과적합 검증 관점**: 장르(무협 패러디·자기계발 혼종)와 피드백 유형이 요리와 전혀 달라, 두 작품을 모두 통과해야 규칙이 일반화된 것.

**검증 결과 (v.9→v.10, 월천 2초고 Flash 2회)**:
- v.9: critique 오판(골드=redesign), R39 미발화 → v.10: 신호 6종 강제 검사 + 근거 기록, R39 생략 금지 추가
- v.10: 신호별 근거는 투명하게 기록되나 **판정은 여전히 critique** (6신호 중 ②약, 나머지 없음으로 평가). R39도 "은유가 일관적"으로 해당 없음 판정
- **간극의 원인 분석**: ① 모델의 호의 편향(요리의 풍자 구조 건과 동일 계열 — 편집자 기각 판정 축적으로만 교정 가능) ② **골드 피드백이 원고 밖 정보에 상당 부분 기반** — 작가의 실화(상암 파업), 기존 저서(<외로움 수업> 등), 협업 히스토리. 에이전트 입력에는 이것이 없음
- **설계 시사점 (v0.3 반영)**: 재설계형 판정의 품질은 **작가 컨텍스트 입력**(이력·기존 작품·기획 의도·시놉시스)을 요구한다 — 지작_Flow.html의 '작가 정보 입력(성격·취향)' 모듈·모드 I(아이디어)와 연결되는 지점. 원고 단독 입력으로는 비평형이 안전한 기본값이며, 재설계형은 작가 컨텍스트가 있을 때 정확해진다
- 캘리브레이션 방법: /lab 월천 실행의 intervention_basis 신호별 판정에 편집자가 채택/기각을 남기면 그것이 재설계 판정의 골드가 된다

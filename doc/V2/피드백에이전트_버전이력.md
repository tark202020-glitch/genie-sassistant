# 피드백 에이전트 버전 이력 (FA-x.y)

*에이전트의 버전별 변화 양상을 추적하는 문서. 에이전트 버전(FA)은 프롬프트·규칙·판정 체계의 묶음 버전이며, 서비스 버전(V1.0xx)과 별개다.*
*모든 실행은 당시의 FA 버전·프롬프트·규칙 버전을 기록하므로(`/lab` 실행 상세의 버전 줄), 지표 대시보드에서 버전 간 성능을 직접 비교할 수 있다.*
*기준 골드: ①『요리는 잘 하는 사람』 전체 1고 + 고래방 전체 피드백(비평형) ②『월천거사 용시비결』 2초고 + 피드백(재설계형) ③『파란장미(유애 이야기)』 파일럿 A 1·2차 + B + 피드백 3종(초고=재설계형, 수정고=첨삭형)*

# Genie Assistant — 채팅 첨부 파일 질의 프로세스

> **시나리오**: 보조작가(블랙위도우) 활성 상태에서 PDF 파일을 채팅에 첨부하고 질문
> 
> **질문**: "자료파일에 기반하되 첨부한 문서를 참고하여 5화 엔딩에 대한 아이디어를 주세요"

---

## 자료 우선순위

| 우선순위 | 자료 유형 | 출처 | 로드 방식 | 역할 |
|:---:|:---|:---|:---|:---|
| 1 | 전용 대본/자료 | 보조작가 전용 (Supabase) | `getFullDocumentText()` 전체 복원 | **주요 기반** — 대본 전체를 읽고 답변 |
| 2 | 채팅 첨부 파일 | 사용자가 직접 첨부 (chat-upload) | `pdf-parse` 텍스트 추출 → 메시지 인라인 | **직접 참고** — 사용자가 지금 보여주고 싶은 자료 |
| 3 | 공유 학습자료 | 공유 자료 (Supabase pgvector) | `searchByVector()` 코사인 유사도 5개 청크 | **보조 참고** — 배경 지식, 작법 이론 등 |
